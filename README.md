# Data Modeling 
## Interview Kickstart Data Engineering Module

This repository contains the code and instructions for following along with the Data Modeling section of Interview Kickstart’s Data Engineering module.

During the live class, we work through three problems, each accompanied by:
- A predefined schema
- A script to generate sample seed data

One metric is implemented live in class. Additional practice questions are included for each problem so you can explore further on your own.

To get started with any problem, navigate into the corresponding directory and follow the steps outlined in the QUESTION.md file.

## Set up
- Install SQLite3 (if you don't have): `brew install sqlite3`
- cd <question>: `sqlite3 data.db < seed.sql`
